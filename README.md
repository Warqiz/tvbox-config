# Marco Movie 自用片源配置（自动维护）

自动维护的 TVBox / 影视仓 配置，每周更新一次：源池扩源 → 全量体检 → 剔除死源 → 按「点开即播」优先级排序。

- 当前片源：**40** 个点播源 + **8** 个直播源
- 最近更新：2026-11-20 10:16

## 使用方法

在 Marco Movie / 影视仓 / TVBox / 映匣 的「设置 → 配置地址」填入下面任一地址：

| 类型 | 地址 | 说明 |
|---|---|---|
| 主地址 | `https://raw.githubusercontent.com/Warqiz/tvbox-config/main/marco_config.json` | GitHub 官方 raw，最快最新 |
| 备用 1 | `https://cdn.jsdelivr.net/gh/Warqiz/tvbox-config@main/marco_config.json` | jsDelivr CDN，国内一般更快 |
| 备用 2 | `https://ghproxy.net/https://raw.githubusercontent.com/Warqiz/tvbox-config/main/marco_config.json` | ghproxy 加速，前两个不通时用它 |

> 填一次即可，之后每周自动更新，无需再改。
